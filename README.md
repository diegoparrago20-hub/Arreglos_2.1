# TestBiblioteca

Interfaz gráfica de un sistema de gestión de biblioteca desarrollada en Java utilizando NetBeans.

## Equipo #2
CONTRERAS RODRIGUEZ JANIS ISABEL

LIRA DOMINGUEZ BRYANT

## Contenido

* JFrame Form: `TestBiblioteca`
* Diseño realizado con Free Design.
* Botones para las operaciones de la biblioteca.
* Campos para título, autor, año e índice.
* Área de resultados mediante JScrollPane y JTextArea.

## Herramientas

* Java
* NetBeans
* Swing
