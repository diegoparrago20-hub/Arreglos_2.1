Sistema de gestión de biblioteca desarrollado en Java utilizando NetBeans.

## Descripción

La aplicación permite crear y administrar una biblioteca mediante objetos `Libro` almacenados en arreglos. Cuenta con una interfaz gráfica para realizar las operaciones principales del sistema.

## Clases principales

* `Biblioteca`: administra la biblioteca y el almacenamiento de los libros mediante arreglos.
* `Libro`: representa los libros con sus datos principales.
* `TestBiblioteca`: contiene la interfaz gráfica del sistema.

## Funciones

* Crear biblioteca
* Mostrar libros
* Agregar libro
* Modificar libro
* Eliminar libro
* Mostrar por índice
* Destruir biblioteca
* Validaciones y manejo de errores

## Herramientas

* Java
* NetBeans
* Java Swing
